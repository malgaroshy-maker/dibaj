## 🖼️ منظومة عرض الصور وضمان استقرارها | Image Architecture & Asset Loading

تم تصميم المشروع لضمان ظهور كافة الصور بنسبة 100% ودون أي مسارات مكسورة عند استضافة الموقع محلياً أو على **GitHub Pages** أو على أي خادم استضافة سحابي:
1. **مسارات نسبية صارمة (Relative Paths)**: جميع مراجع الصور في صفحات HTML وملفات JavaScript تستخدم المسار النسبي `./assets/...` عوضاً عن المسارات المطلقة `/assets/...` التي قد تنكسر عند الاستضافة في مستودعات فرعية (`https://<username>.github.io/<repository>/`).
2. **إعدادات Vite المهيأة للنشر السلس**: تم ضبط `base: './'` في `vite.config.js` لضمان أن كافة ملفات الحزم البرمجية وملفات CSS والخطوط والصور تُبنى بمسارات نسبية تعمل في أي بيئة استضافة.
3. **أصول الشركة المحفوظة**:
   - `public/assets/`: الأصول الرسمية عالية الدقة للموقع (الشعار المفرغ `logo_crest.png`، عينات أقمشة الديباج، صور المجالس الليبية، الستائر، والحرفي).
   - `facebook_extracted_assets/`: الأرشيف الكامل للصور والمنشورات المستخرجة من صفحة فيسبوك الرسمية محفوظة بشكل مستقل للرجوع إليها مستقبلاً.

## 📄 صفحات الموقع وميزاته | Pages & Features

1. **الصفحة الرئيسية (`index.html`)**:
   - شريط علوي فاخر مع شعار "NA" داخل إطار بيضاوي بأوراق الغار.
   - واجهة رئيسية جذابة (Hero Section) تستعرض ستائر القصور الشاهقة والتفصيل الحرفي.
   - بطاقات التشكيلات المميزة (أقمشة الدمقس، ستائر القصور، المجالس العربية الأصيلة).
   - نافذة تفاعلية لحجز استشارات التفصيل الفوري وطلب عروض الأسعار.
   - زر عائم دائم للتواصل الفوري مع كونسيرج الديباج عبر واتساب.

2. **كتالوج ومجموعات الأقمشة (`catalog.html`)**:
   - تصفية فورية وسلسة للأقمشة بحسب التصنيف (ستائر، مجالس، مخمل، جاكار، كتان).
   - حقل بحث فوري سريع يبحث في أسماء الأقمشة ومواصفاتها.
   - بطاقات منتجات تفاعلية تتيح الانتقال السريع لصفحة التخصيص أو حجز موعد.

3. **مخصص الأقمشة وتفاصيل المنتج (`product.html`)**:
   - معرض صور ديناميكي يعرض تفاصيل النسيج.
   - منتقي العينات التفاعلي (Interactive Swatch Selector) لتبديل الألوان والخامات فورياً.
   - **حاسبة الأمتار الذكية (Smart Yardage Calculator)**: تحسب الأمتار المطلوبة للتفصيل بدقة متناهية وفق نوع التطبيق (ستائر بطيات ملوكية 2.5x، تنجيد صالونات، مجالس أرضية).

## 🚀 التشغيل والتطوير المحلي | Getting Started

### المتطلبات
- Node.js (الإصدار 18 فما فوق)
- npm

### التثبيت والتشغيل
```bash
# تثبيت التبعيات
npm install

# تشغيل خادم التطوير المحلي
npm run dev

# بناء الحزمة النهائية للإنتاج
npm run build

# معاينة حزمة الإنتاج
npm run preview
```

## 🌐 النشر على GitHub Pages | Deployment to GitHub Pages

المشروع مزوّد بملف سير عمل تلقائي `.github/workflows/deploy.yml`:
1. عند دفع الكود إلى الفرع الرئيسي (`main`)، يقوم GitHub Actions تلقائياً بتثبيت التبعيات وبناء الموقع بواسطة Vite ونشره على GitHub Pages.
2. لتفعيل النشر من واجهة المستودع على GitHub:
   - اذهب إلى **Settings** > **Pages**
   - في قسم **Build and deployment** > **Source**، اختر **GitHub Actions**.

## 🔒 التحقق الآلي وفحص الجودة | Automated Verification

يتضمن المشروع سكريبتات فحص آلي باستخدام Playwright:
- `python scripts/test_site.py`: لفحص تكامل الصفحات والواجهات والنوافذ التفاعلية وحاسبة الأمتار.
- `python scripts/verify_images.py`: للتحقق الآلي من أن كل صورة في كل صفحة تُحمّل بأبعادها الأصلية الكاملة دون أي خطأ 404.
