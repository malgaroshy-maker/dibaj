## 🎨 نظام التصميم والهوية البصرية | Design System

- **الخطوط العربية ذاتية الاستضافة (Self-Hosted WOFF2)**:
  - **Amiri (أميري)**: للعناوين التراثية وعلامة البراند (أوزان 400 و 700).
  - **IBM Plex Sans Arabic**: للنصوص العصرية والواجهات والأزرار (أوزان 400 و 600).
  - *خالٍ تماماً من خطوط Cairo و Tajawal ودون أي اعتماد على خوادم Google Fonts الخارجية.*
- **الألوان الهيكلية**:
  - الحبر الليلي (`--ink: #221C16`)
  - العاجي التراثي (`--ivory: #F2EAD8`)
  - الحجري العصري (`--stone: #EDEAE4`)
  - الذهبي الحرفي (`--gold: #C9A227`, `--gold-deep: #9A7A18`)
- **لوحة ألوان الأقمشة (8 ألوان رئيسية)**:
  - زمردي (Emerald), توتي (Magenta), نيلي (Royal Blue), زيتوني (Sage), طوبي (Terracotta), رملي (Sand), فحمي (Charcoal), ونعناعي (Mint).
- **قواعد الطباعة العربية الصارمة**:
  - `dir="rtl"` و `lang="ar"`.
  - انعدام تام لأي تباعد بين الحروف العربية (`letter-spacing: 0`).
  - انعدام المائل المصطنع (`font-style: normal`).
  - استخدام الخصائص المنطقية في CSS (`margin-inline`, `padding-inline`, `border-inline-start`).

## 📁 هيكلية الموقع والصفحات | Site Architecture

الموقع مبني بنظام **Static HTML5 / Vanilla CSS / Vanilla JS** بدون أي اعتمادية إجبارية على أدوات البناء، وجاهز للنشر المباشر على **GitHub Pages**:

1. **الرئيسية (`index.html`)**:
   - عرض متحرك بدقة 3 ثوانٍ للمخمل الزمردي والتوتي ودمقس العاج.
   - شريط الألوان الثمانية المباشر (`اختار بلونك`).
   - البوابة المنقسمة: العالم العصري والعالم التراثي.
   - مسار التفصيل في 3 خطوات عملية ("على مقاس بيتك").
   - شريط طرق الدفع المميز: قبول الشيكات المصدقة والحوالات والبطاقة المصرفية **بنفس القيمة وبدون أي زيادة**.
   - خريطة وبيانات المحلين (محل 14 ومحل 76).

2. **الصالونات (`salons.html`)**:
   - صالونات مودرن بأرجل معدنية مذهبة وخشب طبيعي، وصالونات شسترفيلد فاخرة.
   - تبويبات تصفية فورية (الكل / عصري / تراثي).

3. **جلسات ومجالس (`majlis.html`)**:
   - جلسات أرضية متصلة، مجالس خشب زان مذهب، وطاولات نقش ليزر CNC.

4. **الركنيات (`corners.html`)**:
   - ركنيات بوكليه موديل قاعة العرض، وركنيات شامواه وجلد مقلوب أمريكي.

5. **الستائر (`curtains.html`)**:
   - تفصيل ستائر متناسقة بنفس قماش الصالون أو بلون مكمل لديكور الصالة.

6. **أعمالنا والمعرض (`gallery.html`)**:
   - تصفية متقدمة **باللون أولاً** ثم بنوع الموديل.

7. **تواصل معنا (`contact.html`)**:
   - أزرار متكافئة للواتساب ومسنجر فيسبوك والاتصال الهاتفي.
   - تفاصيل محلي سوق أبوسليم مع أرقام السجل التجاري والصناعي.
